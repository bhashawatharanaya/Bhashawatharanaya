# පාලි භාෂාවතරණය 02

පාලි භාෂාවතරණය දෙවන භාගය ඉගෙනීම සඳහා වූ වෙබ් ඇප් එකකි.

## අන්තර්ගතය

- **පාඩම්** – වරනැගිලි වගු සහ නිදසුන් වාක්‍ය
- **වචන කාඩ්පත්** – පාලි වචනය සහ සිංහල අර්ථය
- **ප්‍රශ්න** – ලකුණු සහිත ප්‍රශ්නාවලිය
- **පරිවර්තන** – පාලි → සිංහල සහ සිංහල → පාලි
- **සන්ධි / පද සාධන**
- **අතිරේක විස්තර**

## අන්තර්ගතය වෙනස් කිරීම

සියලු අන්තර්ගතය `index.html` තුළ ඇති `<script>` කොටසේ පහත ලැයිස්තු වල ඇත:

| ලැයිස්තුව | අන්තර්ගතය |
|---|---|
| `LESSONS` | පාඩම් |
| `VOCAB` | වචන |
| `QUIZ` | ප්‍රශ්න |
| `TRANS` | පරිවර්තන වාක්‍ය |
| `SANDHI` | සන්ධි |
| `PADA` | පද සාධන |
| `NOTES` | අතිරේක විස්තර |

> මෙහි ඇති අන්තර්ගතය සාමාන්‍ය පාලි ව්‍යාකරණ ඇසුරින් සකසන ලද නියැදියකි. පොතේ පාඩම් අනුපිළිවෙළට තවම ගළපා නැත.
