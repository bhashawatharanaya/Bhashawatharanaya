# පාලි භාෂාවතරණය 02

පාලි භාෂාවතරණය දෙවන භාගය ඉගෙනීම සඳහා වූ වෙබ් ඇප් එකකි.

## අන්තර්ගතය

- **පාඩම්** – පටුන, විඥාපනය, සංඥා, සන්ධි හැඳින්වීම, සර සන්ධි
- **අභ්‍යාසය 1 · සිංහලට** – වාක්‍ය 15
- **අභ්‍යාසය 1 · පාලියට** – වාක්‍ය 15
- **වචන මාලාව** – ලැයිස්තුව / කාඩ්පත්

සෑම වාක්‍යයක් යටම **පරිවර්තනය**, **සන්ධි / පද සාධන**, **අතිරේක විස්තර** යන බොත්තම් තුන ඇත.

> අන්තර්ගතය පාලිභාෂාවතරණය දෙවැනි පොතෙන් (පොල්වත්තේ ශ්‍රී බුද්ධදත්ත මහානායක ස්ථවිර) ගෙන ඇත.
