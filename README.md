# පාලි භාෂාවතරණය 02

පාලි භාෂාවතරණය දෙවන භාගය ඉගෙනීම සඳහා වූ වෙබ් ඇප් එකකි.

## අන්තර්ගතය

- **පාඩම්** – පොතේ පටුන; සංඥා, සන්ධි හැඳින්වීම, සර සන්ධි (නීති 3)
- **පරිවර්තන** – අභ්‍යාසය 1 (සිංහලට 15, පාලියට 15) සහ එක් එක් වාක්‍යයේ පද සාධන
- **සන්ධි පද සාධන** – පද 62ක සාධනය පියවරෙන් පියවර, සූත්‍ර අනුව පෙරහන
- **ප්‍රශ්න** – ප්‍රශ්න 22ක්
- **වචන** – අභ්‍යාසය 1 වචන මාලාව (ලැයිස්තුව / කාඩ්පත්)
- **අතිරේක විස්තර** – සූත්‍ර සංග්‍රහය සහ සටහන්

## අන්තර්ගතය වෙනස් කිරීම

සියලු අන්තර්ගතය `index.html` තුළ ඇති `<script>` කොටසේ පහත ලැයිස්තු වල ඇත:

| ලැයිස්තුව | අන්තර්ගතය |
|---|---|
| `TOC`, `LESSONS` | පටුන සහ පාඩම් |
| `D(...)` | පද සාධන (`~අ~` = ලොප් වූ අකුර) |
| `S` | සූත්‍ර |
| `EXA`, `EXB` | අභ්‍යාසය 1 වාක්‍ය |
| `VOCAB` | වචන |
| `QUIZ` | ප්‍රශ්න |
| `NOTES` | අතිරේක විස්තර |

> අන්තර්ගතය පාලිභාෂාවතරණය දෙවැනි පොතෙන් (පොල්වත්තේ ශ්‍රී බුද්ධදත්ත මහානායක ස්ථවිර) ගෙන ඇත.
